# 电商财务数据分析智能体 2.0

这是独立于 `shop_manage` 的智能体项目，定位为求职展示和后续产品化开发入口。

## 当前定位

- 自然语言问数
- 财务指标解释
- 部门、主管、组长、产品多维分析
- 趋势和异常诊断
- 表格、图表和分析报告
- 查询依据与审计记录

原系统继续负责数据导入、权限、利润表、仪表盘和后台中控；本项目通过原系统 API 获取真实数据，不复制数据库。

## 规划架构

```text
用户问题
  -> 意图识别
  -> 财务指标语义层
  -> 受控查询工具
  -> 原系统 API
  -> 结果校验
  -> 表格 / 图表 / 中文结论
```

## 原系统地址

默认读取 `http://127.0.0.1:18780`，可通过环境变量 `FINANCE_API_BASE` 修改。
